# GranjaFlow — Curva Oficial do Integrador

Dashboard fixa e interativa baseada na folha oficial de consumo com 112 dias.

## Conteúdo

- curva diária e acumulada;
- reprodução animada da evolução;
- indicadores por dia e semana;
- evolução semanal;
- comparação por fase;
- identificação visual da folha oficial do integrador;
- download do Excel profissional com três abas.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Publicar

O projeto está pronto para GitHub e Vercel. Veja o arquivo

## Dados preservados

A curva possui 112 dias e chega a 259,20 kg/animal. O resumo oficial das seis
fases termina no dia 105, com 237,15 kg/animal. Os dias 106–112 foram mantidos
sem fase informada, conforme a fonte.
